# Portafolio profesional — Angela María Lara Picón

Portafolio web enfocado en desarrollo web y **Java Full Stack** (perfil junior / trainee), construido con HTML5, CSS3 y JavaScript puro, sin dependencias externas de compilación ni frameworks.

## Estructura del proyecto

- `index.html`: estructura semántica principal y contenido de respaldo accesible.
- `css/styles.css`: sistema visual base (modo oscuro por defecto, modo claro opcional y estilos de impresión).
- `js/portfolio-data.js`: datos centralizados en `window.PORTFOLIO_DATA`.
- `js/main.js`: inicialización principal del sitio.
- `img/projects/`: directorio reservado para imágenes de proyectos.

## Cómo abrir el proyecto

1. Ubica el archivo `index.html` en la raíz del proyecto.
2. Ábrelo directamente haciendo doble clic o arrastrándolo a tu navegador web favorito.
3. No requiere servidor local, instalación de paquetes ni proceso de compilación; también es compatible con GitHub Pages usando rutas relativas.
